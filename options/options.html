PageMortem settings

Model server

If your main model is text-only (for example Qwen3-Next), set a vision model such as Qwen3-VL; PageMortem then asks it about screenshots. Leave it blank if the main model accepts images.

Model behaviour

Use “JSON in text” if Agent mode stalls or the server returns tool calls as plain text.

Page text sent per request. ~4 characters ≈ 1 token; keep it well under your server's context size.

Agent safety

Always asks before typing into fields, submitting forms, downloads and buttons like Buy, Delete or Send. Password, payment and ID fields are never filled.
